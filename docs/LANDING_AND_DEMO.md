# 着陆页与产品演示

## 已确认
用户要求先开发着陆页，增加类似 PPT 的标签，展示产品功能和使用方式。继承比赛 experiment；这是当前开发优先级，真实链上功能继续留在后续阶段。

## 执行范围
选择 Sites/React 单页流程，复用现有工程。验收单元为首页产品介绍及一个六页演示播放器；不扩展账户或交易功能。首页浅色纸张/绿色文档视觉，演示深绿大字版式；功能全部明确标记规划或演示。旧工作台保留于 /workspace，仅静态原型。

## 演示大纲
1. 产品价值：已有 AI 编标之后，把标书、合同与确认关联。三步流程图。
2. 链上账号：各自钱包，各自注册，密钥自管。步骤列表。
3. 准备文件：本地计算指纹，原文不公开上链。步骤列表。
4. 发起签署：确认文件、指定甲方、发送链接和原件。步骤列表。
5. 甲方确认：核对指纹，阅读后签署。权限与重复签署说明。
6. 后续核验：篡改合同金额的反例；自检答案为不应通过。

内容依据为本项目对话中的产品设计，不代表链上交易已经实现。使用虚构设备供应项目作为贯穿示例。

## 交付形式
集成在首页“产品演示”标签中，不是 PPTX，也未承诺离线。按钮、页码、键盘 Home/End/左右/空格、手机横向滑动、全屏及失败提示。首尾禁用，窄屏允许滚动，尊重减少动态效果设置。

## 验证
npm run build 成功。真实浏览器验证首页、演示标签、下一页、跳到末页、末页禁用、Home 返回首页、右方向键翻页。1440×900 演示末页截图可读，390×844 无横向溢出。移动触摸手势尚未在真机验证。合约测试为此前未完成工作的测试，不代表本次已通过链上验收。

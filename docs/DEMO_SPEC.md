# MonadSpark 页面与交互说明书 · Demo v1

## 目标和范围
用户明确要求先整理说明书并做可点击 Demo，不使用真实数据。本轮优先完成六个逻辑界面及模拟交互，真实合约工作继续保留在 v0.5 后续计划。
所有企业、文件、注册与交易均为模拟，不连接钱包、不发送链上请求、不上传原文件。使用 Sites 现有私有站点。在线简明说明书位于 /guide。

## 页面及入口
| 界面 | 路径或状态 | 内容与操作 |
| --- | --- | --- |
| 产品首页 | / | 保留产品介绍，增加进入 Demo 入口 |
| PPT 演示 | / 的产品演示标签 | 保留六页说明，不能当作已运行链上功能 |
| 我的工作台 | /workspace | 身份/注册状态、统计、搜索、全部/我发起/待我签/状态筛选、查看详情、新建 |
| 发起签署 | 工作台“发起签署”状态 | 三步：项目与文件 → 指定甲方 → 摘要与同意；支持前后返回 |
| 签署详情 | /workspace?record=编号 | 双方、状态、文件核对、注册、签署、撤销、重新发起、分享、历史 |
| 文件核验 | /workspace?view=verify | 明确选择记录，两份文件分别比对，同时显示业务状态 |

六个逻辑界面不等于六条独立路由；工作台内部使用界面状态，详情可通过编号打开。注册和操作确认采用弹窗。另有 /guide 使用说明。

## 全局交互
- 顶部固定解释演示性质，不出现真实合约地址或假交易编号。
- 角色选择：星河设备（乙方）、远山工程（指定甲方）、其他演示账号、访客。
- 乙方及其他账号初始模拟已注册；远山工程需要注册；访客只读。
- 切换身份清除文件核验和同意状态。确认弹窗打开时不能切换身份或操作结果。
- 操作结果选择：成功、钱包拒绝、查询超时。处理中锁定弹窗操作；拒绝不变更记录；未知继续查询后才模拟成功，不重发。
- 弹窗支持 Tab 焦点循环，普通确认/结果可 Esc 退出；等待或未知状态不能靠 Esc 当作取消提交。
- 重置前确认，恢复三个内置记录和账号注册初态；只操作本 Demo 会话数据。

## 发起交互
- 只有乙方能发起；其他角色进入页面时提供切换乙方按钮。
- 项目名不能为空且最多 60 字；两份示例必须选择原始版才能下一步。
- 第二步指定远山工程或其他演示账号；记录中实际指定谁，谁才可签。
- 第三步核对项目、文件和双方，并勾选确认；按钮提示“模拟发起签署”。
- 成功后生成 DEMO 前缀编号，进入详情，状态待甲方签署，历史写入乙方确认（模拟）。
- 模拟发起使用原始样本，修改版只用于核验场景；真实版将允许用户选择任何合法最终文件。

## 详情角色规则
| 状态/身份 | 能做什么 |
| --- | --- |
| 待签 / 乙方 | 核验、复制演示链接、撤销，不能冒充甲方签署 |
| 待签 / 指定甲方 | 未注册先模拟注册；两份匹配并勾选后模拟签署 |
| 待签 / 其他账号或访客 | 只读核验，显示没有签署权限 |
| 已签 / 所有人 | 核验与查看，无重签或单方撤销入口 |
| 已撤销 / 所有人 | 查看与核验，不能再签；乙方可另建新记录 |
| 不存在 | 提示当前会话没有记录，可回工作台或打开内置例子 |

撤销无需重新选择文件，弹窗解释影响；不能撤销已签终态。纯演示中操作串行，不宣称测试过真实链上竞争。

## 核验规则
- 标书、合同各选原始或修改样本，通过演示标签判断，不计算实际 SHA-256。
- 任意样本变更后清除旧核验和同意结果，需再次核对。
- 两份都原始：一致；其中一份修改：单独标出不一致。
- 文件匹配和记录状态分别显示：已撤销记录的原始文件可以一致，但不能签。
- 访客无需注册或钱包即可核验。

## 数据与分享边界
使用 sessionStorage 的 monadspark-demo-v1，仅存虚构记录及模拟注册状态。当前标签页刷新可恢复，关闭会话或重置可丢失。没有跨用户同步。
复制链接后同时显示可手动复制字段。新建编号只在当前会话有效，跨设备无法共享；内置编号可以从初始种子打开。浏览器禁止存储时仍可在本次页面内体验，但刷新不保证恢复。
不导入朋友源码，无真实 API、钱包密钥、客户文件或授权数据。

## 建议体验脚本
1. 乙方 → 发起 → 两份原始样本 → 指定远山工程 → 勾选并确认。
2. 详情切换指定甲方 → 模拟注册 → 重选原件并核对 → 勾选并签署。
3. 进入核验，合同换修改版，观察文件不一致但历史记录仍已签。
4. 打开另一条待签记录，乙方撤销；切甲方，确认不能再签。
5. 操作结果选择拒绝/超时，检查无变化/未知；搜索无结果；最后重置。

## 第七界面：合同链上记录

新增 /chain?record=编号，签署详情内可进入，读取同一演示会话。可切换合同、展开创建/签署/撤销事件，展示操作方、模拟前后状态及设计中的方法/事件名。历史只保存成功的模拟操作；缺少时间不补造。账户注册属于账号级记录，本地选择/只读核验/提交前拒签不产生链上交易，页面明确解释。
演示不生成交易哈希、区块号、费用、钱包或合约地址；单笔交易链接禁用并说明原因。文件指纹为演示标签。摘要可导出 JSON，mode=DEMO_NOT_ON_CHAIN，真实链字段为 null。
右侧 MonadScan、最新交易 /txs、区块 /blocks、MonadVision 与 Monad 官方文档均新窗口打开，标注真实外网数据不属于 Demo 合同。手动查询支持交易哈希、公开地址及非负区块号，先校验格式，只构造固定测试网域名 URL；格式有效不代表存在，不证明关联本合同。
官方来源：https://docs.monad.xyz/developer-essentials/testnet （本轮取得 .md 核对），列出 https://testnet.monadscan.com/ 和 https://testnet.monadvision.com 。2026-09-05 核实 MonadScan 首页及交易/区块页面，不引用瞬时高度作为固定事实。
验证：链接校验测试先失败后通过；demo/explorer 两项测试通过，npm run build 通过；浏览器已检查已签和已撤销记录切换、模拟编号查询拒绝、区块编号链接生成及 390×844 布局。本轮没有接入真实合同数据或执行链上交易。

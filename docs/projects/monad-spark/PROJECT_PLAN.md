## v0.2 本轮执行基线

- 授权依据：用户“captionrewrite.com 用这个域名，开发一个网站，与这个链结合”，承接此前五步签署实验；本轮由 PM 定日常实现细节。
- 网站流：granular_website_production_flow；唯一单元为签署工作台（账号、创建、签署、核验属于同一不可拆开的文档生命周期）。不建设营销站、完整 AI 编标、收费和真实企业签名认证。
- 设计：深蓝与白色文档工作台，清晰步骤导航、文件信息和右侧签署状态；手机改单列。首屏直接可操作。
- 文案：标题“MonadSpark | 标书与合同签署”；H1“让每一次签署，都对应同一份文件”。清楚显示测试网及实验边界，不保证法律效力。实验 noindex，不做 SEO 获客声明。
- 文件：浏览器本地计算 SHA-256；正文不上链、不上传到服务器。签署双方自行传递原件，甲方导入两份文件后必须指纹一致才能签署。
- 账号：优先连接用户钱包（平台不持有私钥）；测试账号注册记录在合约；钱包地址作为 ID。无钱包时给出明确安装/创建钱包路径，不模拟已注册。
- 合约：注册账号；发起方锁定两份文件指纹及指定签署地址；发起即记为发起方确认；仅指定甲方可签署；不能重复签署、改写指纹；业务编号独立。只用测试网，无资金托管。
- 分享：分享链接只包含合约/记录编号，不含文件正文；读取链上事实恢复进度。
- 核验：重新计算文件指纹，与固定链上记录比较；修改内容必须不匹配。交易成功仅在回执成功后显示；超时保留交易编号供查询。
- 验收：1440×900、390×844、1280×720；连接/注册/错链/余额不足/上传/拒绝/处理中/失败/成功/重复/未授权/文件不匹配；测试合约访问控制与不变性。
- 发布：用户指定 captionrewrite.com，先发布已验证版本后绑定域名；若 DNS 无访问权限则返回精确记录，不编造已生效。费用预算 0，仅已有免费环境与测试币。
- 退出：本次实现结束时交付已验证状态；未通过链上部署或域名验证时分别标明未完成，不冒充可用。未来企业生产需新计划。
- PM：当前 Codex 主代理负责设计、实现、验证与回执，不新增并行角色。

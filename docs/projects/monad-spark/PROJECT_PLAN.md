# MonadSpark 开发计划 v0.4

> 执行者按 superpowers:executing-plans 在当前任务逐项实现；当前不安排多代理。此文件为唯一权威计划，取代 v0.2/v0.3 中相互冲突的当前状态，历史通过 Git 与沟通记录保留。

**目标：** 在已有网站上实现“投标企业发起 → 指定甲方确认 → 双方核验”的 Monad 测试网闭环。
**架构：** Sites/React 承载介绍和工作台，浏览器本地计算文件指纹；钱包提交交易，Solidity 合约执行权限与状态规则。链上为记录来源，不建文件上传服务器，不托管用户私钥。
**技术：** 复用 npm、vinext、React、shadcn、viem、solc、Ganache；部署前核对锁定版本、许可证及当前 Monad 测试网兼容性。

## 2. 立项目标

已有 AI 生成文件作为输入，本项目解决后续文件包关联、双方版本确认及改动识别。比赛演示仅使用虚构资料。
成功标准：真实测试网交易完成双方确认；篡改、未授权、重复签署被拒绝；刷新后从链上恢复事实。演示页不能代替功能成功证据。

## 3. 范围

包含：钱包连接、链上注册、两份文件指纹、指定甲方、发起确认、甲方签署、只读核验、记录分享、交易恢复；建议纳入“签署前由发起方撤销”。
排除：重新实现 AI 编标、PDF 签章编辑器、多人会签、文件云盘、手机号/邮箱登录、平台生成私钥、付费、主网、企业实名及正式电子签章法律方案。
首版钱包以桌面注入式兼容钱包为支持路径；手机支持介绍和只读核验。手机钱包内签署需单独实测才能声明支持，不本轮引入 WalletConnect 服务。

## 4. 实验边界和全局约束

- 测试网配置基线 chainId 10143；实际开工再次验证 RPC 返回链号，禁止切主网 143。
- 0 新增付费预算；测试币和原有可用免费环境。没有测试币不能捏造部署成功。
- 文件按原始字节 SHA-256；两份分别记录，不混成无角色的哈希集合；单份 0 < size ≤ 10 MiB。
- 文件正文、文件名、企业身份资料和密钥不写公开链/日志/仓库；文件只保留浏览器内存。
- 地址、指纹、记录状态是公开信息；不声称完全保密、身份真实或测试网永久存证。
- 分享定位使用链号＋受支持合约＋编号；本地持久化仅公开编号与待确认交易信息。
- 成功需要回执成功并读到相应业务状态；未知交易继续查询，不自动重复写入。
- 已有网站保留，先单独完成工作台功能；当前不自动公开网站、仓库或提交比赛。
- 不承诺固定分钟交付。按里程碑验收，域名、钱包支持和平台资格独立报告。

## 6. 接口、状态与依赖

合约方法/字段/状态详见 FLOW_REVIEW；实现及测试必须采用同一 ABI，不能再沿用旧 bool signed 的 tuple 假设。

```ts
// 计划接口；待创建，不代表现有代码
import type { Address, Hex } from 'viem';
type RecordKey = { chainId: number; contract: Address; id: bigint };
type FilePair = { bidHash: Hex; contractHash: Hex };
type Agreement = FilePair & { creator: Address; counterparty: Address;
  createdAt: bigint; signedAt: bigint; status: 0 | 1 | 2 | 3 };
type TxState = 'awaiting-wallet' | 'pending' | 'unknown' | 'success' | 'reverted' | 'rejected' | 'cancelled';
// hashFile(file: File): Promise<Hex>
// readAgreement(key: RecordKey): Promise<Agreement>
// trackTransaction(hash: Hex, onState: (state: TxState, hash: Hex) => void): Promise<void>
```

写操作先 simulateContract；创建成功后解码 AgreementCreated 获取 id，不猜 agreementCount。签署前前端检查，合约再次强制检查。Gas 使用估算而非夸大的固定上限。
依赖：可用测试网 RPC/测试币、两个独立测试钱包、域名 DNS 控制、Sites 访问范围和比赛资格。未知的依赖不阻止无关模块开发。

## 9. 风险与处理

- 已签记录不支持单方删除或撤销；重新发起不会自动使旧记录失效，界面须明确。
- 没有私钥找回/换签署人/自动到期；误填地址在待签时撤销并重建。新增撤销规则待评审。
- 指纹仅证明文件字节一致；不判断合法性、真实性、企业授权或用户已阅读。
- 测试网可能重置；不承诺长期留存。未来正式企业使用另立 production 计划。
- 域名控制、网站受众、比赛资格依赖外部条件；可并行准备，不编造结果。

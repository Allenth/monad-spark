## 4. 生产完整性或实验边界

实验学习问题草案：一个可核验的文档版本确认流程，能否帮助演示参与者理解链上留证价值？尚待用户认可。

时间/成本：本轮只做文档，新增付费预算 0；比赛阶段到 2026-09-05 18:30 截止，之后只有主办方明确许可才能继续提交。
可简化：经批准后可限定参与角色、文件种类及单一流程。
不可简化：真实结果、权限、密钥隔离、失败恢复、原创与提交规则。
成功/失败：后续范围批准时冻结指标；当前不能宣称实验成功。
停止/到期：期限届满、无明确范围或违反资格要求即停止提交工作并重评；不自动续期。
生产晋升：禁止自动晋升；需新 production 计划及全部门禁。当前不是生产系统。

## 8. 验收标准与证据计划

当前文档验收：覆盖全部重要沟通、来源可追溯、纠正记录明确、秘密不入库、相对链接有效。
后续功能验收待 M1 冻结；不得用此草案放行。
后续网站选流：本轮没有 UI 工作，不预选；开工前只能选一个适用流并记录理由、单元、范围及五项门禁（设计、文案/SEO、实现、状态、集成）。
拟议证据要求：桌面 1440×900、手机 390×844 及受限高度 1280×720，最终设计时确认；真实截图、交互回执、Go/No-Go。
状态：正常/空/加载/成功/失败/拒绝/无权限/切错链/长文件名/边界文件/刷新与重试；不能忽略。
安全：合成文件，无密钥/正文隐私泄露；正式签约法律要求未研究。
构建、性能、部署和回滚必须有实际运行证据；当前全部未验证。

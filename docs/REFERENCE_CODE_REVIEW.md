| 参考做法 | MonadSpark 处理 |

## 不能直接沿用的细节

1. verify 只按清单指纹查询，没有对冻结包指纹进行核验；网页却提示也可选择冻结包，冻结包通常无法通过这个清单索引找到对应记录。我们必须按记录同时比较两份有明确角色的文件。
2. frozenBundleHash 没有非零校验；我们两份指纹都校验。
3. 脚本等待回执后没有完整核对执行状态、替换与恢复；我们的成功判断按 v0.5 回执＋链上重读执行。
4. 找不到索引不能单独证明文件遭篡改；可能未存证、查错网络/合约或使用了另一份文件。我们的核验基于明确记录，查询失败与内容不一致分开。
5. 合约地址是占位零地址，没有从该 ZIP 取得可验证的链上部署回执。
6. 附件关于改名、首次推送及比赛原创性的自述未由本轮验证，不能作为我们的资格证明或修改 Git 历史的依据。
